This is a vibe coded app created for my own personal use, it converts most containers into MKV and MP4. For transcoding it uses the H.264 codec for maximum client support when using online multimedia streaming apps such as Emby, Plex and Jellyfin. It will also do straight copies (no transcode). The built in Brightness, Contrast, Saturation, Denoise and Sharpen can be adjusted using sliders and previewed live on a pop out preview pain.  The code has been compiled on both Linux and Windows. As it uses FFmpeg FFprobe and FFplay these need to be installed in your path or directly in the folder containing the app.
